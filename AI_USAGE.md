# AI Usage Guide

Before redesigning a lecture:
1. Read `DESIGN_SYSTEM.md`.
2. Read `docs/components.md`.
3. Read `docs/rtl.md`.
4. Read `docs/typography.md`.
5. Inspect the master template when available.
6. Follow `docs/workflow.md`.

For redesign-only tasks, preserve supplied content and terminology. Do not invent unsupported facts or silently correct scientific claims.

Component mapping:
- Definition → Definition
- High-yield → Golden Tip
- Common confusion → Test Trap
- Clinical relevance → Clinical Note
- Comparison → Comparison table
- Visual explanation → Figure
- Section synthesis → Quick Review

Check paragraph bidi, RTL runs, Persian language metadata, complex-script fonts, mixed Persian/English readability, number placement, headings, tables, headers and footers.

After generation inspect representative pages for overflow, broken tables, awkward page breaks and mixed-direction text.
