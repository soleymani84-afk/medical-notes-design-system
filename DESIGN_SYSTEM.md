# Medical Notes Design System — Specification

## Purpose
Single source of truth for the visual language, document architecture and component rules.

## Document architecture
Cover → Course metadata → Table of contents → Component guide → Chapter → Topic → Body → Semantic components → Figures/Tables → Summary → Quick Review → Questions → References

## Heading hierarchy
- H1: Chapter / major section
- H2: Main topic
- H3: Subtopic
- H4: Local subsection

## Semantic components
Definition, Golden Tip, Test Trap, Clinical Note, Comparison, Figure, Quick Review, Chapter Summary, Review Questions.

## Color semantics
- Navy: identity and primary structure
- Blue: definitions and structured learning
- Gold: high-yield information
- Burgundy: warnings and test traps
- Green: clinical relevance
- Neutral gray: secondary information

## Tables
Use for comparison and compact structured information. Keep cells concise and provide adequate padding.

## Figures
**شکل X — عنوان**
[figure]
*توضیح شکل:* optional
*منبع:* when available

## Layout
Prioritize whitespace, visual rhythm, consistent margins, predictable spacing and intentional page breaks.

## Mixed language
Persian is dominant. English terms, Latin abbreviations and numbers must remain readable without breaking RTL flow.

## Editing policy
For redesign-only tasks, preserve content and terminology. Do not silently add scientific facts or corrections.

## Versioning
MAJOR = breaking change; MINOR = compatible feature/component; PATCH = documentation/fix.

Current version: **1.0.0**
