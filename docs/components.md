High-yield memorization point. Gold accent + pale gold background.

Common confusion or exception. Burgundy accent + pale burgundy background.

## Clinical Note
Clinical implication/application. Green accent + pale green background.

## Comparison Table
Use when entities share comparison dimensions.

## Figure
Figure number + concise title + image + optional note + source.

## Quick Review
Short recall points at the end of a section.

## Chapter Summary
Synthesis of core ideas.

## Review Questions
Questions must match the source and requested difficulty.

## Anti-patterns
Avoid excessive boxes, decorative icons without meaning, giant headings, dense full-page tables and arbitrary color changes.
