# Typography

## Hierarchy
H1 = Chapter; H2 = Topic; H3 = Subtopic; H4 = Local subsection; Body = Explanation; Caption = Figure/table caption; Note = Secondary metadata.

Use readable Persian fonts with Arabic-script support and a safe fallback.

For mixed Persian/English:
- preserve medically useful Latin spelling
- keep abbreviations intact
- avoid arbitrary spaces
- preserve scientific symbols

Use bold selectively.
