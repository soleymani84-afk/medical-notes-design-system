# Design Philosophy

## Content before decoration
A course note is an educational interface. Visual design should make the main topic, essential facts, common confusions, clinical relevance and memorization points easy to identify.

## Visual hierarchy
Chapter → topic → subsection → body → semantic callout.

## Controlled visual density
Whitespace and restrained components prevent visual fatigue.

## Semantic repetition
The same meaning should always use the same visual treatment.
