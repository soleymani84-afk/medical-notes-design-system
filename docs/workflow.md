# Production Workflow

## Phase 1 — Source inspection
Identify file type, extract structure and preserve terminology.

## Phase 2 — Content policy
Determine whether the request is redesign, proofreading, scientific verification, restructuring or question generation.

## Phase 3 — Semantic mapping
Map content to headings and semantic components.

## Phase 4 — Construction
Apply page layout, typography, colors, RTL structure, headers/footers and components.

## Phase 5 — Technical validation
Check OOXML and mixed-direction text.

## Phase 6 — Visual QA
Inspect representative pages and fix overflow, broken tables, awkward breaks and inconsistent spacing.

## Phase 7 — Delivery
Provide requested DOCX/PDF and a concise change summary.
