# Layout System

## Page
Priorities: readable margins, strong heading rhythm, consistent paragraph spacing, whitespace and stable headers/footers.

## Header
University/course identity + lesson/chapter identity + subtle separator.

## Footer
Page number + optional document identifier.

## Cover
University identity, course title, Persian title, English subtitle when useful, educational image and academic-year/session metadata.

## Page breaks
Use intentional breaks before major chapters. Avoid orphan headings.

## Visual rhythm
Maintain consistent spacing between headings, body text, callouts, figures, captions and tables.
