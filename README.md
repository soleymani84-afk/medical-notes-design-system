# medical-notes-design-system
mother model
When redesigning a course note using this repository:

1. Read DESIGN_SYSTEM.md
2. Read docs/components.md
3. Read docs/rtl.md
4. Inspect the master DOCX template
5. Preserve source content unless explicitly asked to edit
6. Use the defined component system
7. Do not invent new colors/components without justification
8. Validate RTL and mixed Persian/English text
9. Export DOCX and PDF
10. Visually inspect the final output
