# Medical Notes Design System

Reusable visual and technical design system for professional Persian medical course notes.

## Goals
- Fully RTL Persian document structure
- Consistent academic visual identity
- Semantic hierarchy for chapters, topics, definitions, tips, warnings, clinical notes, figures and tables
- Reliable Persian + English + Latin abbreviation + number handling
- Reusable templates and AI instructions

## Core palette
Navy #17365D | Medical Blue #245B88 | Cyan #3F8FAE | Burgundy #8F233F
Clinical Green #3E7D5A | Gold #C69A2B | Text #202B36 | Line #D8DEE5
